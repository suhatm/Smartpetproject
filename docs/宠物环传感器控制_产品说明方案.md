## 1. 背景与目标

### 1.1 现状问题与移除决议

当前项目的调试/控制通道处于"多轨并行"状态。经评审，以下三条旧路径**在 task-V1.06 正式移除**：

| 现有通道 | 用途 | 问题 | 决议 |
|---|---|---|---|
| SWD mailbox（`test_mailbox.c`，`swd_mailbox_v2`） | `power_domain_gui.py` 电源 GUI、`zombie_test.py` | 必须插 J-Link 才能控制，脱离调试器即失效；nrfutil 单次调用数秒，交互卡顿 | **移除** |
| BLE LED 服务（`e5a00001`） | nRF Connect App 点灯 | 通用 App 无传感器面板，仅调试用 | **移除**（LED 控制并入 Sensor Hub 指令 0x01） |
| BLE IMU 服务（`e5a00010`） | `imu_ble_monitor.py` 看 IMU 波形 | 单一传感器，无电源/QVAR/PVDF | **移除**（IMU 数据并入统一帧 TYPE 0x01/0x02） |
| RTT 日志（printk） | bring-up 自检 | 只读、需 SWD，现场无法使用 | 保留（救砖手段，与上位机无关） |

### 1.2 目标

1. 控制通道**统一收敛到 BLE GATT**：一台 PC 上位机完成全部调试与控制
2. 新建 Python 上位机 **"宠物环传感器控制"**（PetRing Console）
3. 固件新增统一 **Sensor Hub GATT 服务**：所有传感器数据经统一帧格式上报，上位机经指令特征统一下发控制
4. GUI 覆盖：
   - LED0/LED1 开关控制
   - 三路电源域控制与测试矩阵（单开/单关/全开/全关）
   - 双六轴（U4 主板 + U1 柔性板）数值与原始数据波形
   - 双路静电感应（QVAR-A/B）数值、波形与**阈值设定**
   - PVDF 压电链路电压值与波形
   - **麦克风录音控制**：左右声道选择、录音时长设定、开启/停止、录音文件上位机本地播放
   - **电池电量显示**：电压/百分比/充放电状态，低电告警（数据源 nPM1300 电量计）
   - 原始数据帧监视 + 手动指令下发

### 1.3 非目标（本期不做）

- 手机 App（iOS/Android）开发
- 云端同步；上位机本地数据落盘为可选增强（见 §9 待完善清单）
- OTA/DFU（保留现有 mcuboot 路径）
- 量产测试工装（本上位机定位研发/调试工具，协议设计兼顾后续量产复用）

### 3.2 功能区明细

**A. 连接栏**
- 扫描过滤：广播名 `SmartPet` + 服务 UUID `e5a00020`
- 连接后自动：请求 MTU 247 → 读固件信息（0x24）→ 订阅 0x21/0x23 → `GET_STATUS` 拉全模块状态
- 断线自动重连（默认开），重连后恢复订阅与开关状态同步
- **电池电量指示**：连接栏常显电池图标+百分比+电压（>50% 绿 / 20~50% 黄 / ≤20% 红），充电中显示 ⚡；数据源 BATTERY 帧（0x08，2s 周期），连接后立即 `GET_BATTERY(0x0C)` 刷首屏；低电（≤15%）经 EVENT 0x03 弹告警

**B. 模块状态灯（左栏）**
- 绿=PRESENT / 灰=ABSENT / 橙=DEGRADED，与固件连接状态机一一对应
- 柔性板未插时 U1/QVAR_A/TEMP 灰显"未接入"而非报错——与固件降级语义对齐
- 数据源：MODULE_STATUS 帧（0x10，1Hz + 变更即发）与 EVENT 0x01

**C. LED 控制**
- LED0（红）/LED1（蓝）独立开关 → 指令 `LED_SET(0x01)`
- override 语义：上位机控制期间电源 UI 状态机显示挂起；BLE 断开自动归还（协议 §7.4）

**D. 电源域控制与测试矩阵**
- SENS / STORE / ANALOG 三域独立开关 → 指令 `PWR_SET(0x02)`
- 测试矩阵一键操作：**单开**（点某域"开"）、**单关**（点"关"）、**全开**、**全关**
- 每域开关旁显示实测状态灯（来自状态帧电源域实况位，非按钮状态——可验证硬件真实通断）
- 联动语义：ANALOG 断电时 PVDF 自动暂停（波形归零、状态转灰）；对采集中的域断电，固件先暂停域内传感器（协议 §7.4）

**E. 六轴 IMU（U4 + U1）**
- 每颗：ax/ay/az（mg）、gx/gy/gz（dps×10）六路数值 + 加速度/陀螺仪波形
- 原始数据即协议载荷原始值（int16 未换算），与帧监视器可互相印证
- U1 ABSENT 时整组灰显

**F. 静电感应 QVAR（A/B 双通道）**
- 每通道：raw 数值（int16 LSB）+ 波形 + **阈值设定**（|Δraw|，指令 `QVAR_THR_SET(0x08)`，带滞回）
- 波形上绘制 ±阈值线；越限时通道触发灯变红，同时收到 `EVENT 0x04 QVAR_THR_CROSSED`（事件日志可见）
- 物理量换算（nV）待标定后在上位机侧完成，本期显示原始 LSB

**G. 压电膜 PVDF**
- heart_mv / raw_mv / ref_mv 三路电压值（mV，大字显示）
- 波形：heart−ref 与 raw−ref 去基线差分（ref_mv≈1500mV 为 VBIAS 虚地）
- 健康判据沿用固件自检口径：ref_mv ∈ 1200~1800mV（协议 §10.3）

**H. 麦克风录音**
- 声道选择：左 / 右 / 立体声（ch_mask）
- 录音时长设定：1~60s（0=手动停止）
- 控制：开始 / 停止 → 指令 `REC_CTRL(0x07)`
- 存储路径：设备端录至 **SD 卡**（PCM 16kHz/16bit，双声道 64KB/s 超 BLE 实时吞吐，故不走实时流）
- 播放：录音完成后 `REC_READ(0x0A)` 触发设备端经 **0x07 AUDIO_FILE 帧分块上传**，上位机收齐拼 WAV 后**本地播放**
- 文件管理：`REC_LIST(0x09)` 列文件、`REC_DELETE(0x0B)` 删除

**I. 数据帧监视器**
- 原始帧滚动列表：时间戳、TYPE 名、SEQ、hex 全文（SYNC/TYPE/SEQ/LEN/PAYLOAD/CRC8）
- 暂停滚动、按 TYPE 过滤、导出 CSV（正式版）

**J. 指令终端**
- CMD(hex) + PARAMS(hex) 手动输入发送 → 0x22 Write
- 快捷按钮：LED 开关 / GET_STATUS / GET_VERSION / PING
- 应答区按 seq 匹配高亮（0x23 Notify，TYPE=0x20 CMD_ACK）

## 5. 通信协议概览（V0.4 修订后）

> 完整定义见《宠物环传感器控制_通信协议.docx》V0.4。**V0.4 相对 V0.3 的变更**：percent 算法定稿 nPM1300 库仑计 SOC（nrf_fuel_gauge 库+电池模型），帧格式不变。**V0.3 相对 V0.2 的变更**：新增 0x08 BATTERY 帧（电池电压/百分比/充放电标志，源 nPM1300 电量计）、GET_BATTERY 指令（0x0C）；EVENT 0x03 LOW_BATTERY 由预留转正（增 percent 字段，15% 门限+5% 滞回）；新增 10.7 电池监测时序。V0.2 变更：废弃 e5a00001/e5a00010 两旧服务；新增录音控制与文件传输指令、QVAR 阈值指令、0x07 AUDIO_FILE 帧、三个新 EVENT。

### 5.1 GATT 服务布局（UUID 基座 `e5a0xxxx-1e5c-4b8f-9a2d-6c0f7e8d9a0b`）

| UUID 尾段 | 角色 | 属性 |
|---|---|---|
| `e5a00020` | Sensor Hub 服务 | — |
| `e5a00021` | 数据流（传感器→上位机，含 AUDIO_FILE） | Notify |
| `e5a00022` | 指令下发（上位机→固件） | Write / Write Without Response |
| `e5a00023` | 应答与事件（固件→上位机） | Notify |
| `e5a00024` | 固件信息（版本/分支/编译时间） | Read |
| ~~`e5a00001/02`~~ | ~~LED 服务~~ | **V1.06 废弃删除** |
| ~~`e5a00010~`~~ | ~~IMU 流服务~~ | **V1.06 废弃删除** |

### 5.2 统一数据帧（≤ MTU-3，小端）

```
┌────────┬──────┬──────┬──────┬─────────────┬───────┐
│ SYNC   │ TYPE │ SEQ  │ LEN  │ PAYLOAD     │ CRC8  │
│ 0xAA55 │ 1B   │ 1B   │ 1B   │ 0~240B      │ 1B    │
└────────┴──────┴──────┴──────┴─────────────┴───────┘
```

- **TYPE**：0x01 IMU_U4 / 0x02 BODY_IMU_U1 / 0x03 QVAR / 0x04 PVDF / 0x05 TEMP / 0x06 MIC / 0x07 AUDIO_FILE / **0x08 BATTERY（V0.3 新增）** / 0x10 MODULE_STATUS / 0x20 CMD_ACK / 0x21 EVENT；0x80+ 保留
- 每类载荷首字节为模块状态位图；ABSENT 模块不发数据帧只发状态帧
- 单 notify 包允许串联多帧（MTU 自适应打包）

### 5.3 指令集（V0.3 全量）

| CMD | 名称 | 参数 | 说明 |
|---|---|---|---|
| 0x01 | LED_SET | mask(bit0=LED0,bit1=LED1) | 唯一 LED 入口（旧 LED 服务已废） |
| 0x02 | PWR_SET | domain(0/1/2), onoff | 三路电源域（单开/单关；全开全关=连发三条） |
| 0x03 | SENSOR_EN | sensor_id, onoff | 六路传感器启停 |
| 0x04 | RATE_SET | sensor_id, hz | 采样率（IMU/QVAR 支持 15/30/60Hz） |
| 0x05 | QVAR_CFG | ch, zin(0~3) | QVAR 输入阻抗（2400/730/300/255 MΩ） |
| 0x06 | REPROBE | sensor_id | 热插拔重探测 |
| **0x07** | **REC_CTRL** | action(0停/1启), ch_mask, duration_s(2B) | **新增：录音控制，录至 SD 卡** |
| **0x08** | **QVAR_THR_SET** | ch, thr(2B), hyst(1B) | **新增：QVAR 触发阈值+滞回** |
| **0x09** | **REC_LIST** | — | **新增：列 SD 录音文件（ACK 带列表）** |
| **0x0A** | **REC_READ** | file_id(2B) | **新增：请求上传文件（0x07 帧流）** |
| **0x0B** | **REC_DELETE** | file_id(2B) | **新增：删除文件** |
| **0x0C** | **GET_BATTERY** | — | **V0.3 新增：请求即时 BATTERY 帧（首屏刷新/低频轮询）** |
| 0x10 | GET_STATUS | — | 请求全模块状态帧 |
| 0x11 | GET_VERSION | — | 请求固件信息 |
| 0x7F | FACTORY_PING | token(4B) | 连通性自检（回显 token） |

### 5.4 事件帧（EVENT 0x21，V0.3 全量）

| event_id | 名称 | 说明 |
|---|---|---|
| 0x01 | MODULE_STATE_CHANGED | 模块状态变迁（含热插拔恢复） |
| 0x02 | WDT_RESET | 看门狗复位上报 |
| 0x03 | LOW_BATTERY | **V0.3 转正**：低电告警 mv(2B)+percent(1B)，≤15% 触发，20% 滞回恢复 |
| **0x04** | **QVAR_THR_CROSSED** | **新增：QVAR 越限触发（ch+方向+raw）** |
| **0x05** | **REC_STATE** | **新增：录音状态（开始/停止/完成+file_id）** |
| **0x06** | **REC_FILE_DONE** | **新增：文件上传完成（总字节+CRC32 校验）** |

## 7. 数据流向分析（上传 / 下发+回复 / 待完善）

### 7.1 需要上传（设备 → 上位机，Notify 0x21/0x23）

| 数据 | 承载 | 触发方式 | 说明 |
|---|---|---|---|
| 六轴原始数据 ×2 | TYPE 0x01/0x02 | 周期 30Hz | SENSOR_EN 使能后流式 |
| QVAR A/B 原始值 | TYPE 0x03 | 周期 30Hz | 含 valid 位图 |
| PVDF heart/raw/ref | TYPE 0x04 | 周期（默认 100Hz） | ANALOG 域上电为前提 |
| 温度 | TYPE 0x05 | 1Hz | U2 在位时 |
| 麦克风 RMS | TYPE 0x06 | 2Hz | 电平监视 |
| 全模块状态 | TYPE 0x10 | 1Hz + 状态变更即发 | 状态灯唯一权威来源 |
| 录音文件内容 | TYPE 0x07 | REC_READ 请求后流式 | 分块+offset，完结算 CRC32 |
| **电池电量** | **TYPE 0x08** | **周期 2s（可 GET_BATTERY 轮询）** | **VBAT mV + 百分比 + 充放电标志** |
| 指令应答 | TYPE 0x20（0x23 通道） | 每条指令一条 | seq 匹配 |
| 异步事件 | TYPE 0x21（0x23 通道） | 事件即发 | 阈值触发/录音状态/WDT/低电 |

### 7.2 需要通信下发 + 回复（上位机 → 设备，Write 0x22 → CMD_ACK 0x20）

| 操作 | 指令 | 回复内容 |
|---|---|---|
| LED0/LED1 开关 | 0x01 LED_SET | result |
| 电源域单开/单关/全开/全关 | 0x02 PWR_SET（全开全关=连发 3 条） | result ×N |
| 传感器启停 | 0x03 SENSOR_EN | result |
| 采样率设定 | 0x04 RATE_SET | result |
| QVAR 阻抗设定 | 0x05 QVAR_CFG | result |
| **QVAR 阈值设定** | **0x08 QVAR_THR_SET** | result（触发后经 EVENT 0x04 异步上报） |
| 热插拔重探测 | 0x06 REPROBE | result（0=已在位，1=仍 ABSENT） |
| **录音开始/停止（声道+时长）** | **0x07 REC_CTRL** | result（完成经 EVENT 0x05） |
| **录音文件列表/下载/删除** | **0x09/0x0A/0x0B** | ACK 带数据 / 随后 0x07 帧流 / result |
| **电池电量即时查询** | **0x0C GET_BATTERY** | **ACK 后立即一帧 0x08** |
| 状态查询 | 0x10 GET_STATUS | ACK 后立即一帧 0x10 |
| 版本查询 | 0x11 GET_VERSION | ACK 带 ASCII 版本串 |
| 连通性自检 | 0x7F FACTORY_PING | token 原样回显 |
